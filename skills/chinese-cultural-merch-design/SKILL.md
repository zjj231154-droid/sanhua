# 中式文创周边设计

工作流必须按顺序进行：产品类型 → 可量产材质 → 真实尺寸 → 用户视觉素材 → 最终生图提示词。

每一步只收集当前所需信息；未完成当前步骤，不进入后续步骤。最终提示词必须保留素材的核心构图、色彩、文字、书法或 IP 特征，禁止粗暴贴图或改写主体。输出同一产品 2—3 个一致视图，明确真实材质、可生产工艺、尺寸、留白、文化语义与商业产品摄影要求。默认方向为新中式、东方美学、雅致、年轻化、可量产，并避免廉价旅游纪念品感与明显 AI 感。
