# 精修

负责将自然语言修图需求转化为稳定、可执行的图片编辑任务。该 Skill 是 `media_agent` 的图片编辑垂直入口：当任务涉及修图、重绘、去水印、扩图、参考图编辑或 Logo 动画时优先使用本 Skill。

## 生图前 Plan（必须执行）

首次收到图片编辑需求时，不得立即调用生图或编辑工具。先解析用户的自然语言和输入图片，形成一份简短的「生图计划」，并等待用户确认后再执行。

### 1. 提取已知条件

从用户原话和图片中提取以下信息，用户已经明确的内容不要重复询问：

- **用途**：电商主图、小程序点单、社交媒体、海报、详情页、头像等。
- **尺寸**：具体像素、宽高比、横版/竖版/方形及文件格式。
- **编辑类型**：整图编辑、局部重绘、去除对象、扩图、换背景、参考图编辑、画质增强或 Logo 动画。
- **主体与保留项**：必须保持不变的产品、人物、包装、Logo、文字、视角、构图、姿势或细节。
- **场景**：摄影棚、室内、户外、酒馆、餐厅、自然环境，以及时间、季节和空间氛围。
- **装饰**：允许出现的道具、植物、食材、灯光、纹理及装饰密度。
- **视觉方向**：写实或插画、色调、光线、情绪、商业质感和参考风格。
- **文字要求**：必须保留、删除或新增的准确文案；未明确要求时不要自行添加文字。
- **交付要求**：单张或多版本、是否需要透明背景、目标输出位置。

### 2. 询问缺失项

至少确认尺寸/比例、场景和装饰。若用户未说明，应结合用途给出一个推荐默认值，同时提供少量容易选择的方向。将仍会显著影响结果的问题一次性问完，通常控制在 1–5 个，不逐条来回追问。

示例：

```text
生图计划
- 用途：小程序商品头图
- 推荐尺寸：1:1 方形，建议 1024×1024 PNG
- 主体：保留原产品、包装和拍摄视角
- 场景：待确认
- 装饰：待确认
- 文字：默认不新增

请确认：
1. 场景希望是明亮摄影棚、生活方式场景，还是夜间氛围场景？
2. 装饰希望极简、少量点缀，还是较丰富？有无指定道具？
3. 是否采用上述推荐尺寸？
```

如果用户已经完整说明所有关键条件，只需展示整理后的计划并请其确认，不要为了走流程重复提问。用户回复“按你推荐的来”“可以”“确认”或给出修改意见后，即视为完成确认。

### 3. 确认门槛

- 用户确认前，不调用任何生图、重绘、扩图或动画生成工具。
- 若用户修改计划，更新计划中受影响的字段并再次确认。
- 只有会显著改变画面或交付规格的信息才需要确认；工具内部参数由执行者自行决定。
- 不把合理默认值伪装成用户要求，必须明确标注为“推荐”或“默认”。

## 核心能力

- **整图编辑**：根据自然语言指令修改整张图片的风格、内容、构图。
- **局部重绘 / Inpaint**：对指定区域进行重绘或移除对象。
- **扩图 / Outpaint**：在图片边缘扩展内容，保持风格一致。
- **去水印**：识别并移除图片中的水印、标志或瑕疵。
- **超分 / 画质增强**：提升图片分辨率与细节。
- **参考图编辑**：以参考图引导目标图的编辑方向。
- **Logo 动画**：将 Logo 转为语义化 SVG 并生成 CSS 动画或帧序列。

## 典型工作流

1. 解析用户修图意图和输入图片，明确编辑类型（整图/局部/扩图/去水印/Logo 动画）。
2. 输出「生图计划」，询问缺失的尺寸、场景、装饰和关键约束。
3. 等待用户确认；若用户调整要求，更新计划后再次确认。
4. 根据确认后的计划选择工具和提示词，执行图片编辑。
5. 检查结果是否符合计划与保留项，产物保存到 `storage/outputs/`。
6. 返回结果路径、变更说明、最终规格与版权/授权提醒。

## 质量标准

- 编辑前后差异明确，输出图片路径可访问。
- 局部编辑保持未修改区域不变。
- 扩图内容与原图风格、光影、透视一致。
- 对外部素材提醒版权和授权风险。
