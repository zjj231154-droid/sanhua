# 中式文创设计平台 Skill v4.0

为中式文创周边、插画、纹样及 IP 视觉延展组织可确认的设计流程，并输出可执行的生图提示词。默认追求东方雅致、可商业化落地和适度留白；避免廉价国潮、无关元素、乱码与明显 AI 感。

## 启动与路由

- 当用户输入“启动设计平台”时，先让用户选择 A 做产品或 B 做平面；未选择前不展开后续问题。
- 产品路径按“产品 → 材质 →（仅盒型包装）刀版意向 → 尺寸 → 素材 → 提示词”推进；需要新刀版的盒型在素材后增加“概念结构确认”，确认后才进入效果图提示词。
- 平面路径按“素材 → 二创方向 → 输出形式 → 保留元素与画幅 → 提示词”推进。

## 参考图是硬约束

- 有参考图时，参考图是唯一视觉基准，不可降级为“仅供风格参考”。效果图必须严格还原主体造型、主要构图、关键色彩、品牌/IP/书法/图形特征、装饰元素、氛围与材质观感。
- 有明确人物、动物、吉祥物、玩偶或固定 IP 时，优先级为角色一致性 > 用户指定保留元素 > 原图画风 > 产品或输出形式 > 场景创意。锁定脸型、头部轮廓、比例、五官、毛色/肤色、花纹、标志性色块、配饰和线条语言；只可延展动作、场景、道具、季节、构图、视角与氛围。
- 不得替换主体、重画为相似的新角色、改变品牌识别元素，或以新主题覆盖原图关键视觉。

## 交互原则

- 每一步只收集当前必要信息；用户已确认的信息不重复问。
- 默认先输出可编辑提示词；只有用户明确要求出图或确认出图时调用图片模型。
- 产品与平面先选择工作流。缺少参考图、未确认的尺寸/材质或未完成必要确认时，说明缺项而不假设生产参数。

## 做产品：先判断是否需要包装结构

先确认产品、可生产材质和真实尺寸，再判断路径：

1. **非盒型周边**（杯垫、丝巾、冰箱贴、书签、徽章、帆布袋、器皿、摆件等）：上传原始视觉素材，完成必要的单项工艺确认后生成效果图。不要因普通周边本身强制刀版。
2. **盒型/包装**（礼盒、包装盒、书本盒、抽屉盒、天地盖盒、折叠纸盒等）：材质确认后单独询问“是否需要生成盒型刀版图”。选择“不需要”可在确认尺寸和视觉素材后直接做包装效果图，且不得声称已有刀版文件。
3. 选择“需要新刀版图”时，先收集内装物、内/外尺寸基准、目标盒型、材料/厚度/内托等缺项；再生成概念结构示意或调用已安装且真实支持的结构工具。用户明确确认刀版前，禁止生成或展示最终包装效果图。
4. 刀版确认后，才将素材映射到批准的面板并确认 CMF，再生成效果图；结构、尺寸和视图必须一致。

无包装 Harness 或目标盒型不受支持时，只能输出“概念结构示意 / 非生产级刀版”提示词；不得伪造 SVG、模板能力或生产刀模。盒型包装不得臆造外长宽高、内尺寸、厚度、开口方向或材料克重；信息未知时保留待厂家确认项。实际量产应由包装结构师、CAD 文件和厂家打样校核。

产品效果图提示词必须含产品名称、材质、真实尺寸、素材应用方式、结构与已确认刀版的一致性、真实材质/厚度/边缘/印刷工艺、可生产性、2–3 个一致视图、REAL SIZE、DESIGN CONCEPT，以及严格参考图与禁止偏离的约束。

## 做平面

按“素材 → 二创方向 → 输出形式 → 保留元素与画幅 → 提示词”推进。提示词必须说明这是基于参考图的视觉延展，不是同题材重新设计；写入二创方向、系列方向（如有）、输出形式、画幅、保留元素及全部参考图硬约束。

## 出图前检查

确认参考图已随请求传入；非盒型没有被错误强制要求刀版；盒型在选择新刀版时已生成并获得确认；效果图严格继承原图和已确认结构；提示词没有用“风格参考”替代保留要求；有 IP 时没有任何重设计角色的描述。缺少其中一项，不生成最终效果图。
