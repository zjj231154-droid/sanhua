## 权限和 API 改动

- `functions/_lib/task-ownership.js`：统一本人任务判断与 Session 查询范围；工作区管理员不能因此读取其他人的个人任务。共享上传素材仍保留资产权限逻辑。
- `tasks`：列表、按 ID 读取、更新、取消和隐藏均校验本人；忽略客户端伪造 owner/workspace。旧取消入口复用任务中心的真实取消逻辑。
- `task-center`：本人汇总、详情、恢复快照、取消、重试、归档；取消锁按同一工作记录统一，避免不同 ID 别名重复取消。新增 `POST /:id/archive-results` 恢复结果归档。
- `video-tasks`：本人列表、按 ID 读取、下载；查询和下载其他人的任务统一 404。供应商真实进度写入 `progressSource=provider`，未提供进度时不补造百分比。
- `drama-projects`、`scripts`、`text-records`：补齐本人项目、剧本版本、文本读取/恢复/更新等权限；文本列表在分页前过滤本人。
- `assets`、原图文件路由、`generated-results`、`libraries`：个人生成结果在详情、查询、下载、归档和计数中保持隔离；明确共享的工作区素材仍可用。个人结果文件不跨 Session 复用长期 HTTP 缓存。
- `task-store`、`work-record-store`：新记录默认 private，持有 owner/workspace；保存源项目/镜头、生成参数；敏感字段从嵌套快照中剔除；取消与归档状态不能被迟到结果复活。
- 图片输出归档前持久化待归档结果和固定资产 ID；部分写入后重试会复用已有资产并补齐索引，避免再次请求模型或重复生成图片。

历史记录没有 owner/createdBy 时，不会凭同工作区关系自动认领给另一个账号。底层记录仍保留；如需修正归属，须另行核实历史所有者。

## UI 改动

- `TaskProgress.jsx`：只从本人任务中心取数。默认按 running/retrying、queued、ready、draft 及更新时间选择单项任务；可在卡片选择“圆环跟踪此任务”。选择按账号/工作区保存在 Session UI 偏好中；任务结束后自动换项。
- 圆环不再计算平均进度。无真实进度时显示处理中；任务数量徽标只表示本人活动数量；任务卡片各自显示独立进度。
- 账号/工作区切换时重建任务组件和业务页面，清空任务/草稿缓存，忽略旧请求的迟到响应。
- 圆环移入顶栏安全停靠区，顶栏为其预留宽度，不再拖动到生成按钮区域。
- `DramaVideoStage.jsx`：拆分镜头列表、编辑与结果、生成设置；失败卡片提供原因和定向重试；提示词保存错误可重试；设置滚动区与批量操作分组；未勾选时显示禁用原因。
- 低于 1100px 使用可切换面板；极窄内容容器也切换面板；低于 720px 使用单栏操作布局。恢复视频任务时还原具体镜头、最新提示词、时长、比例和清晰度。

## 已执行验证

```text

```

最终结果：32 个测试文件、158 项测试通过；Vite 生产构建通过；diff 空白检查通过。

新增/扩展测试覆盖：

- 两个真实登录 Session、同一 main 工作区的 owner 和 editor；双向尝试读取、取消、重试、归档、更新、下载对方任务均返回 404，管理员也无默认绕过。
- 列表忽略伪造身份参数；创建忽略伪造 owner/workspace；共享上传素材仍可读取。
- 个人生成图片、原始文件、视频下载、文本/恢复、剧本版本、项目及结果归档的所有权校验。
- 重建存储适配器后恢复步骤、子路由、素材和参数；草稿取消后历史保留；供应商取消成功/失败、平台停止跟踪提示、迟到结果不复活。
- 多任务不取平均；选择跟踪对象、任务结束后切换、未知进度不显示阶段估算、跨账号缓存和迟到请求隔离。
- 助手输出进入统一中心；实际注入图片归档索引写入故障，恢复后不重复请求模型、不重复建资产；任务快照去除凭据字段。
- 短剧具体镜头和参数恢复；失败原因/定向重试；提示词保存失败与重试；面板切换；打开视频按钮和下载入口。

上述为自动化测试，不等同于生产双浏览器人工验收。供应商调用在自动化中使用受控响应，未为本次验收消耗生产模型额度。
